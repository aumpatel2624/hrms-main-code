# Payroll Entry

Create and process a company payroll batch with a separate outcome for each employee.

![Payroll Entry](../screenshots/payroll-entry-light.png "light")

![Payroll Entry](../screenshots/payroll-entry-dark.png "dark")

## Select employees

Choose company, frequency and dates. Active employees with matching assignments and no slip for those exact dates are selected. Attendance validation excludes employees with missing non-holiday attendance.

## Process the batch

Create slips, inspect each result, then submit. One employee's failure does not stop the others. Negative net pay fails submission. Failed rows are final for that entry.

## Cancel

Cancel the entry to cancel its linked slips. A submitted batch means every eligible row was attempted; inspect failed rows separately.
