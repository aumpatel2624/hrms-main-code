**Not documented as separate files** (core ERPNext/framework doctypes referenced by HRMS but out of this app's scope): Company, Branch, Department, Holiday List, Holiday, User, Employee (the master itself — see [[Employee]] note below), Project, Task, Timesheet, Journal Entry, Payment Entry, Loan.

> [!note] Employee doctype
> `Employee` is the hub every module hangs off, but it is technically part of core
> ERPNext (`erpnext.setup.doctype.employee`), extended by HRMS via `hrms/overrides/employee_master.py`
> doc_events. No agent produced a dedicated `Employee.md` file for this reason — its
> HRMS-specific behavior (onboarding validation, approver role sync, job applicant/offer
> linkage, transfer/separation triggers) is documented inline across [[Employee Onboarding]],
> [[Employee Separation]], [[Employee Transfer]], and each module's `_Overview.md`. Treat
> every `[[Employee]]` wikilink in this vault as pointing conceptually to that hub, even
> though no single file owns it.
